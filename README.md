#NOMBRE DEL PROYECTO: 
##A2D_SM

#DESCRIPCIÓN:
##A2D SM es un sistema de trazabilidad diseñado para una planta procesadora de fruta, cuyo objetivo es modernizar y complementar el sistema legado actual, permitiendo gestionar el flujo de recepción y procesamiento de tarjas de fruta de manera más segura, mantenible y auditable.

##La solución está dirigida a operadores de recepción, operadores de proceso, administradores y personal relacionado con la gestión de la planta, quienes requieren registrar, consultar y controlar la información asociada a la trazabilidad del producto.

##El proyecto busca resolver la dependencia de un sistema antiguo difícil de mantener, entregando una plataforma moderna que permita controlar la recepción de fruta, procesamiento de tarjas, gestión de catálogos y auditoría de cambios, asegurando la disponibilidad y confiabilidad de la información.
